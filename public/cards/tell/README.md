# Hungarian Tell deck

ULTIRÓ bundles the unmodified [Hungarian playing cards PNG pack](https://github.com/tomasdrus/hungarian-playing-cards/tree/6c4c7252af5aef50e189bc033ca4f69feb469b69/cards-medium), uploaded by tomasdrus: 32 faces and one back, all 181 × 293 pixels.

The game uses these faces with a [custom ULTIRÓ card back](../ultiro-back.svg).

These files are for this private checkout. The uploader [does not provide a redistribution license](https://github.com/tomasdrus/hungarian-playing-cards/issues/1#issuecomment-1102422590).
